# 픽셀 캐릭터 생성 핸드오버 문서
> **Canvas 2D로 픽셀 캐릭터를 코드만으로 그리는 방법**  
> 다른 프로젝트에서 캐릭터 생성 시 참고용

---

## 1. 전체 구조 요약

- **이미지 파일 없이** Canvas 2D API만으로 캐릭터를 그림 (의존성 0개)
- `fillRect`(사각형)과 `ellipse`(원)만으로 머리/몸/팔/다리 구성
- 색상 4개(`body`, `hair`, `skin`, `shoe`)만 바꾸면 캐릭터 커스터마이징 가능
- 아이소메트릭(2.5D) 뷰에서 사용하지만, **캐릭터 자체는 정면 2D**

## 2. 캐릭터 색상 정의

캐릭터마다 `colors` 객체 하나로 외형을 결정한다.

// 플레이어 색상

## 3. 캐릭터 그리기 핵심 코드

### 3-1. 전체 구조 (위→아래 순서)

```
① 그림자 (ellipse) — 캐릭터 발밑
② 다리 (fillRect × 2) — 좌우 다리
③ 몸통 (fillRect) — 가장 큰 사각형
④ 가운 (fillRect, 선택) — NPC일 때 반투명 흰색 오버레이
⑤ 팔 (fillRect × 2) — 좌우 팔
⑥ 머리 (fillRect) — 피부색 사각형
⑦ 머리카락 (fillRect) — 머리 위에 얹힘
⑧ 눈 (fillRect × 2) — 검정 점 2개
```

### 3-2. 핵심 치수 (하드코딩 값)

```javascript
const bh = 28;  // 캐릭터 전체 높이 기준점

// 각 파츠별 크기 (px)
// 다리:   5×4 (좌우 각각)
// 몸통:   16×18
// 가운:   12×14 (NPC만)
// 팔:    3×10 (좌우 각각)
// 머리:   14×12
// 머리카락: 16×5
// 눈:    2×2 (좌우 각각)
// 그림자:  14×6 (타원)
```

### 3-3. 실제 그리기 함수 (최소 버전)

다른 프로젝트에서 바로 복사해 쓸 수 있는 **독립 함수**:

```javascript
/**
 * 픽셀 캐릭터를 Canvas에 그린다
 * @param {CanvasRenderingContext2D} ctx - Canvas 컨텍스트
 * @param {number} x - 캐릭터 중심 X 좌표
 * @param {number} y - 캐릭터 발밑 Y 좌표
 * @param {object} colors - { body, hair, skin, shoe }
 * @param {string} name - 캐릭터 이름 (머리 위에 표시)
 * @param {number} facing - 바라보는 방향 (1=오른쪽, -1=왼쪽)
 */
function drawPixelCharacter(ctx, x, y, colors, name, facing) {
  const { body, hair, skin, shoe } = colors;
  const bh = 28; // 캐릭터 높이 기준
  facing = facing || 1;

  // ① 그림자
  ctx.beginPath();
  ctx.ellipse(x, y + 2, 14, 6, 0, 0, Math.PI * 2);
  ctx.fillStyle = 'rgba(0,0,0,0.15)';
  ctx.fill();

  ctx.save();
  ctx.translate(x, y);

  // ② 다리 (좌/우)
  ctx.fillStyle = shoe;
  ctx.fillRect(-6, -4, 5, 4);   // 왼다리
  ctx.fillRect(1, -4, 5, 4);    // 오른다리

  // ③ 몸통
  ctx.fillStyle = body;
  ctx.fillRect(-8, -bh + 6, 16, 18);

  // ④ 팔 (좌/우)
  ctx.fillStyle = skin;
  ctx.fillRect(-11, -bh + 8, 3, 10);  // 왼팔
  ctx.fillRect(8, -bh + 8, 3, 10);    // 오른팔

  // ⑤ 머리 (피부)
  ctx.fillStyle = skin;
  ctx.fillRect(-7, -bh - 4, 14, 12);

  // ⑥ 머리카락
  ctx.fillStyle = hair;
  ctx.fillRect(-8, -bh - 6, 16, 5);

  // ⑦ 눈 (facing 방향으로 살짝 이동)
  ctx.fillStyle = '#222';
  const eyeShift = facing * 1;
  ctx.fillRect(-4 + eyeShift, -bh + 1, 2, 2);  // 왼눈
  ctx.fillRect(2 + eyeShift, -bh + 1, 2, 2);   // 오른눈

  ctx.restore();

  // ⑧ 이름 라벨 (그림자 + 흰색)
  ctx.font = 'bold 10px "Segoe UI", sans-serif';
  ctx.textAlign = 'center';
  ctx.fillStyle = 'rgba(0,0,0,0.5)';
  ctx.fillText(name, x, y - bh - 10);
  ctx.fillStyle = '#fff';
  ctx.fillText(name, x - 0.5, y - bh - 10.5);
}
```

## 4. 애니메이션 시스템

캐릭터 상태에 따라 파츠 위치를 `Math.sin()`으로 미세하게 움직인다.

### 4-1. 상태 종류

| 상태 | 설명 | 애니메이션 |
|------|------|-----------|
| `idle` | 가만히 서 있음 | 머리 좌우 미세 틸트 + 눈 깜박임 |
| `patrol` / `player` | 걷는 중 | 다리 교차 스윙 + 팔 교차 스윙 |
| `notice` | 플레이어 발견 | 위아래 바운스 + 이모티콘 순차 표시 |
| `talk` | 대화 중 | 팔 제스처(말하기/듣기 전환) + 고개 기울임 |

### 4-2. 걷기 애니메이션

```javascript
const t = Date.now();

// 다리 스윙 (좌우 교차)
const legSwing = Math.sin(t / 500) * 3;
ctx.fillRect(-6, -4 + legSwing, 5, 4);   // 왼다리: +swing
ctx.fillRect(1, -4 - legSwing, 5, 4);    // 오른다리: -swing

// 팔 스윙 (다리와 반대)
const armSwing = Math.sin(t / 500) * 4;
ctx.fillRect(-11, -bh + 8 + armSwing, 3, 10);   // 왼팔
ctx.fillRect(8, -bh + 8 - armSwing, 3, 10);     // 오른팔
```

**핵심:** `Math.sin(Date.now() / 속도) * 진폭`
- 속도(ms): 500 = 적당한 걸음 속도
- 진폭(px): 3~4 = 자연스러운 움직임

### 4-3. 대기(idle) 애니메이션

```javascript
const t = Date.now();

// 머리 좌우 틸트 (매우 느리게)
const headTilt = Math.sin(t / 1500) * 2;  // 2도 범위
ctx.save();
ctx.rotate(headTilt * Math.PI / 180);
// ... 머리 그리기 ...
ctx.restore();

// 몸 좌우 미세 흔들림
const bodyLean = Math.sin(t / 2000) * 1;  // 1px 범위

// 눈 깜박임 (가끔씩만)
if (Math.sin(t / 3000) > 0.95) {
  ctx.fillStyle = skin;
  ctx.fillRect(-5 + eyeShift, -bh + 1, 10, 2);  // 눈 위치에 피부색 덮기
}
```

### 4-4. 발견(notice) 바운스 + 이모티콘

```javascript
// 위아래 바운스
const bounceY = Math.sin(Date.now() / 300 * Math.PI) * 8;
// 캐릭터 전체를 jumpY만큼 위로 이동
ctx.translate(x, y - Math.abs(bounceY));

// 그림자 크기도 바운스에 따라 조정 (높이 뛰면 그림자 작아짐)
const shadowScale = 1 + bounceY / 20;
ctx.ellipse(x, y + 2, 14 * shadowScale, 6 * shadowScale, ...);

// 이모티콘 순차 표시: ❗ → ❓ → 💬
const emojiSequence = ['❗', '❓', '💬'];
const emojiInterval = 400;  // 400ms마다 전환
// emojiIndex를 타이머로 관리
```

### 4-5. 대화(talk) 제스처

```javascript
const t = Date.now();

// 말하기 모드: 팔을 적극적으로 흔듦
if (talkPhase === 'speak') {
  const armL = Math.sin(t / 200) * 5 - 3;  // 빠르고 큰 움직임
  const armR = Math.sin(t / 250 + 1) * 4 - 2;
}

// 듣기 모드: 팔 정지 + 고개 기울임
if (talkPhase === 'listen') {
  const armL = -2;   // 고정
  const armR = -1;   // 고정
  const headTilt = 5; // 5도 기울임 (경청 포즈)
}

// 말하기 ↔ 듣기 전환 주기: 800ms
```

## 5. NPC 상태머신

캐릭터의 행동을 4단계 상태로 관리한다.

```
idle → patrol → notice → talk
 ↑        ↑        ↓       ↓
 └────────┴── (플레이어 멀어짐) ──┘
```

### 상태 전환 조건

```javascript
const NPC_NOTICE_RADIUS = 2.5;  // 그리드 단위 감지 거리

// idle → patrol: 일정 시간(idleDuration) 경과
// patrol → idle: 웨이포인트 도착 (거리 < 0.2)
// idle/patrol → notice: 플레이어가 반경 2.5 이내 접근
// notice → talk: 이모티콘 시퀀스 완료 후 (약 1.2초)
// talk/notice → patrol: 플레이어가 반경 밖으로 이탈
```

### NPC 데이터 구조

```javascript
const npcDefinition = {
  id: 'scan',                  // 고유 ID
  name: 'Dr. Scanner',        // 표시 이름
  gx: 4, gy: 3,               // 초기 그리드 위치
  speed: 0.005,                // 이동 속도 (그리드/ms)
  idleDuration: 800,           // idle 유지 시간 (ms)
  facing: 1,                   // 바라보는 방향 (1=오른쪽, -1=왼쪽)
  state: 'patrol',             // 초기 상태

  // 순찰 경로 (웨이포인트 배열)
  waypoints: [
    { gx: 3, gy: 2 },
    { gx: 8, gy: 2 },
    { gx: 9, gy: 4 },
    { gx: 5, gy: 4 },
    { gx: 3, gy: 3 }
  ],
  wpIndex: 0,                  // 현재 목표 웨이포인트 인덱스

  // 외형
  colors: { body: '#42a5f5', hair: '#1565c0', skin: '#ffe0bd', shoe: '#333' },

  // 모션 프로필
  motion: { gestureType: 'point' },  // 'point' 또는 'wave'
};
```

}

## 8. 아이소메트릭 좌표 변환

캐릭터를 2.5D 맵에 배치하려면 그리드 좌표를 아이소 좌표로 변환해야 한다.

```javascript
const TILE = 40;
const ISO_W = TILE * 2;  // 80px
const ISO_H = TILE;      // 40px

// 그리드 → 아이소 스크린 좌표
function toIso(gx, gy) {
  return {
    x: (gx - gy) * (ISO_W / 2),
    y: (gx + gy) * (ISO_H / 2)
  };
}

// 사용
const screenPos = toIso(character.gx, character.gy);
drawPixelCharacter(ctx, screenPos.x, screenPos.y, colors, name, facing);
```

## 9. 깊이 정렬 (앞뒤 겹침 처리)

아이소메트릭에서 캐릭터가 가구/벽 앞뒤로 올바르게 겹치려면 Y좌표 기준 정렬이 필요하다.

```javascript
// 모든 오브젝트를 배열에 모아서 sortY 기준 오름차순 정렬
const drawList = [];

// NPC 추가
npcs.forEach(n => {
  drawList.push({ sortY: n.gy + n.gx * 0.001, type: 'npc', data: n });
});

// 플레이어 추가
drawList.push({ sortY: player.gy + player.gx * 0.001, type: 'player' });

// 가구/벽 추가
furniture.forEach(f => {
  drawList.push({ sortY: f.r + f.c * 0.001, type: 'furniture', data: f });
});

// 정렬 후 순서대로 그리기 (뒤에 있는 것부터)
drawList.sort((a, b) => a.sortY - b.sortY);
drawList.forEach(item => {
  // item.type에 따라 해당 그리기 함수 호출
});
```

**포인트:** `sortY = gy + gx * 0.001` — Y가 같을 때 X로 미세 정렬

## 10. 색상 유틸리티

캐릭터/가구에 명암을 줄 때 사용하는 색상 함수:

```javascript
// 색상을 밝게(+) 또는 어둡게(-) 조절
function shadeColor(hexColor, amount) {
  let num = parseInt(hexColor.replace('#', ''), 16);
  let r = (num >> 16) + amount;
  let g = ((num >> 8) & 0xff) + amount;
  let b = (num & 0xff) + amount;
  r = Math.max(0, Math.min(255, r));
  g = Math.max(0, Math.min(255, g));
  b = Math.max(0, Math.min(255, b));
  return '#' + ((1 << 24) + (r << 16) + (g << 8) + b).toString(16).slice(1);
}

// 사용 예: 같은 색의 어두운 버전 (그림자 면 등)
const darkBody = shadeColor('#42a5f5', -20);
```
